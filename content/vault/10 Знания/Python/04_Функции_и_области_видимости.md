## Сигнатура и способы передачи аргументов

```python
def score(
    values: list[float],
    /,                         # до / — positional-only
    threshold: float = 0.5,
    *,
    normalize: bool = True,    # после * — keyword-only
) -> float:
    ...
```

Positional-only полезны, когда имя параметра — деталь реализации. Keyword-only делают вызов самодокументируемым: `score(xs, normalize=False)`.

```python
def collect(*args: int, **kwargs: str) -> tuple[tuple[int, ...], dict[str, str]]:
    return args, kwargs
```

`*args` собирает лишние позиционные аргументы в tuple, `**kwargs` — именованные в dict. При вызове `f(*items, **options)` происходит распаковка.

## Изменяемое значение по умолчанию

Default-выражения вычисляются один раз при создании функции:

```python
def bad_add(value: int, bucket: list[int] = []) -> list[int]:
    bucket.append(value)
    return bucket
```

Безопасный вариант:

```python
def add(value: int, bucket: list[int] | None = None) -> list[int]:
    if bucket is None:
        bucket = []
    bucket.append(value)
    return bucket
```

Это относится и к dict/set, и к экземплярам пользовательских классов.

## Функции — объекты

Функцию можно хранить, передавать и возвращать:

```python
from collections.abc import Callable

def apply_twice(function: Callable[[int], int], value: int) -> int:
    return function(function(value))

def double(value: int) -> int:
    return value * 2

assert apply_twice(double, 3) == 12
```

`lambda` — небольшое выражение без обычных statements:

```python
rows = [("a", 3), ("b", 1)]
rows.sort(key=lambda row: row[1])
```

`map` и `filter` ленивы в Python 3. Для простой трансформации comprehension часто читается яснее:

```python
squares = [value * value for value in values if value > 0]
```

## LEGB

Поиск имени идёт по областям:

1. Local — текущая функция;
2. Enclosing — внешние функции;
3. Global — модуль;
4. Builtins — встроенные имена.

Присваивание создаёт локальное имя, если не указаны `global` или `nonlocal`.

```python
def make_counter() -> Callable[[], int]:
    count = 0

    def increment() -> int:
        nonlocal count
        count += 1
        return count

    return increment
```

`global` меняет имя уровня модуля и обычно делает код труднее тестировать. `nonlocal` работает с ближайшей enclosing-областью.

## Замыкание и late binding

Замыкание — функция вместе с захваченным окружением:

```python
def multiplier(factor: int) -> Callable[[int], int]:
    def multiply(value: int) -> int:
        return value * factor
    return multiply
```

Лямбды в цикле захватывают переменную, а не её текущее значение:

```python
bad = [lambda: i for i in range(3)]
print([f() for f in bad])  # [2, 2, 2]

good = [lambda i=i: i for i in range(3)]
print([f() for f in good])  # [0, 1, 2]
```

Default `i=i` вычисляется на каждой итерации создания функции.

## Docstring и type hints

```python
def mean(values: list[float]) -> float:
    """Вернуть среднее непустой последовательности.

    Raises:
        ValueError: если values пуст.
    """
    if not values:
        raise ValueError("values must not be empty")
    return sum(values) / len(values)
```

Аннотации не проверяются интерпретатором автоматически. Они документируют контракт и помогают IDE, `mypy`/`pyright` и ревью. Подробнее: [[11_Typing_Testing_Code_Quality]].

## Предскажите результат

```python
def f(value: int, seen: set[int] = set()) -> bool:
    existed = value in seen
    seen.add(value)
    return existed

print(f(1), f(1))
```

Ответ: `False True`, потому что один default-set живёт между вызовами.

## Что сказать интервьюеру

> Функции в Python — объекты. Аргументы связываются с локальными именами, defaults создаются один раз при определении функции. Области видимости ищутся по LEGB. Замыкание сохраняет доступ к именам внешней функции, но в циклах возникает late binding: значение читается при вызове, а не при создании. Type hints описывают контракт, но не дают runtime-проверку сами по себе.
