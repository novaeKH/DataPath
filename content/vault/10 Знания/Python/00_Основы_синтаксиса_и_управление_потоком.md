# 00. Основы Python: синтаксис и управление потоком

## Что изучим

Этот урок нужен до коллекций, функций и библиотек Data Science. После него вы должны уметь прочитать небольшую программу, понять порядок выполнения строк, написать условие и цикл, а также объяснить, чем значение отличается от переменной.

## Как выполняется программа

Python читает файл сверху вниз. Отступы задают блоки кода, поэтому они являются частью синтаксиса.

```python
price = 120
has_discount = True

if has_discount:
    price = price * 0.9

print(price)
```

Сначала создаётся число `120`, затем имя `price` связывается с ним. Условие проверяет `has_discount`. Так как значение истинно, выполняется строка внутри блока `if`.

## Переменные и типы

Переменная — имя, связанное с объектом. Тип принадлежит объекту, а не имени.

```python
value = 10
value = 10.5
value = "ten"
```

Основные типы:

- `int` — целые числа;
- `float` — числа с плавающей точкой;
- `bool` — `True` и `False`;
- `str` — текст;
- `None` — отсутствие значения.

Проверить тип можно через `type(value)`. Явное преобразование выполняют функции `int`, `float`, `str`, `bool`.

```python
age = int("21")
ratio = float("0.75")
label = str(1)
```

Не любое преобразование допустимо: `int("двадцать")` вызовет `ValueError`.

## Операторы

Арифметика:

```python
7 + 3   # 10
7 - 3   # 4
7 * 3   # 21
7 / 3   # 2.333...
7 // 3  # 2, целая часть
7 % 3   # 1, остаток
7 ** 3  # 343
```

Сравнения возвращают `bool`:

```python
score >= 0.8
category == "premium"
value != 0
```

Логические операторы:

```python
is_adult = age >= 18
can_apply = is_adult and has_documents
needs_review = is_adult and not has_documents
```

Для проверки принадлежности используют `in`:

```python
country in {"RU", "SE", "US"}
```

## Условия

```python
if score >= 0.8:
    decision = "approve"
elif score >= 0.5:
    decision = "manual review"
else:
    decision = "reject"
```

Условия проверяются сверху вниз, выполняется первая подходящая ветка. Порядок важен: если сначала проверить `score >= 0.5`, более строгая ветка `score >= 0.8` уже не сработает.

### Truthy и falsy

В логическом контексте ложными считаются `False`, `None`, ноль и пустые коллекции.

```python
if not rows:
    print("Нет данных")
```

Такой код обычно лучше, чем `if len(rows) == 0`.

## Цикл `for`

`for` перебирает элементы iterable-объекта:

```python
values = [3, 5, 8]
for value in values:
    print(value ** 2)
```

Когда нужен индекс:

```python
for index, value in enumerate(values):
    print(index, value)
```

Параллельный обход:

```python
for feature, weight in zip(features, weights):
    print(feature, weight)
```

## Цикл `while`

`while` выполняется, пока условие истинно:

```python
attempt = 0
while attempt < 3:
    attempt += 1
```

Он удобен, когда число повторений заранее неизвестно. Ошибка в условии может создать бесконечный цикл.

## `break`, `continue`, `pass`

- `break` полностью останавливает ближайший цикл;
- `continue` переходит к следующей итерации;
- `pass` ничего не делает и используется как временная заглушка.

```python
for value in values:
    if value is None:
        continue
    if value < 0:
        break
    print(value)
```

## Comprehension

Короткая запись построения коллекции:

```python
squares = [x * x for x in values if x >= 0]
label_by_id = {row["id"]: row["label"] for row in rows}
unique_lengths = {len(text) for text in texts}
```

Comprehension хорош для одного понятного преобразования. Если внутри несколько условий, побочных эффектов или сложная логика, обычный цикл читается лучше.

## Ввод, вывод и строки

```python
name = "Ilya"
score = 0.8732
message = f"{name}: score={score:.2f}"
print(message)
```

F-string позволяет вставлять значения и форматировать числа. Пользовательский ввод из `input()` всегда является строкой и требует проверки.

## Частые ошибки новичка

- использовать `=` вместо `==` в сравнении;
- смешивать строки и числа без преобразования;
- неправильно ставить отступы;
- менять список во время его обхода;
- писать слишком сложный comprehension;
- использовать `while`, когда обычный `for` понятнее;
- ожидать, что `input()` вернёт число.

## Мини-практика

Напишите функцию-пока-без-функции: по списку оценок посчитайте число значений не ниже `0.7`, пропуская `None`. Затем выведите долю успешных оценок среди известных.

```python
scores = [0.91, None, 0.43, 0.78, 0.69]
```

Ожидаемый ход: цикл → проверка `None` → два счётчика → деление с защитой от нуля.
