# Коллекции Python: выбираем по задаче

Есть последовательность посещений: Анна, Борис, Анна, Вера. Для журнала нужны все события в исходном порядке. Для списка посетителей человек нужен один раз. Для отчёта требуется число посещений каждого человека. Одни исходные данные требуют разных структур.

Будем различать последовательность, фиксированную запись, соответствие и множество. Важно не количество известных методов, а понимание того, какую информацию сохраняет структура и какие операции делает удобными.

## Список хранит порядок и повторы

Список `list` — последовательность, которую можно менять. Индексы начинаются с нуля. Отрицательный индекс отсчитывается с конца. Срез включает левую границу и не включает правую:

```python
visits = ["Анна", "Борис", "Анна", "Вера"]
print(visits[0])      # Анна
print(visits[-1])     # Вера
print(visits[1:3])    # ['Борис', 'Анна']
visits.append("Глеб")
print(visits.pop())   # Глеб
```

`append` добавляет один объект, `extend` добавляет элементы другой последовательности. `pop` удаляет и возвращает элемент. Метод `sort` сортирует на месте и возвращает `None`; функция `sorted` создаёт новый список. Запись `visits = visits.sort()` ошибочна, если вы ожидаете получить отсортированный список в переменной.

В CPython список устроен как расширяемый массив ссылок. Для доступа по индексу не нужно обходить предыдущие элементы. Вставка в начало требует сдвинуть остальные ссылки, а поиск `name in visits` может проверить весь список.

Обозначение `O(n)` описывает рост работы пропорционально числу элементов, `O(1)` — отсутствие такого роста. Это не точное время в миллисекундах. Добавление в конец списка в среднем по длинной серии операций имеет стоимость `O(1)`: редкое расширение буфера компенсируется множеством дешёвых добавлений.

## Кортеж описывает фиксированную запись

Кортеж `tuple` удобен для координат или пары «имя, возраст». Его состав нельзя менять. Распаковка связывает отдельные элементы с именами:

```python
person = ("Анна", 27)
name, age = person
print(name, age)   # Анна 27

a, b = 10, 20
a, b = b, a
print(a, b)        # 20 10
```

При обмене сначала вычисляется правая часть, затем меняются имена. Кортеж не делает вложенные списки неизменяемыми — это следует из модели предыдущего урока. Выбирайте кортеж, когда фиксированная структура записи имеет смысл, а не просто ради предполагаемой экономии памяти.

## Словарь связывает ключ со значением

Словарь `dict` отвечает на вопрос «какое значение связано с ключом?». У ключа одно текущее значение. Повторная запись ключа заменит его значение.

```python
counts = {}
for name in ["Анна", "Борис", "Анна", "Вера"]:
    counts[name] = counts.get(name, 0) + 1
print(counts)   # {'Анна': 2, 'Борис': 1, 'Вера': 1}
```

Цикл последовательно присваивает `name` очередное имя. При первом появлении Анны `get` возвращает запасной ноль; после прибавления получится единица. При втором появлении вернётся единица, и счётчик станет равен двум.

Для поиска используется хеш — целое число, вычисляемое для ключа. При совпадении хешей проверяется равенство. Ключ должен быть хешируемым: хеш не меняется за время жизни объекта, а равные ключи имеют одинаковые хеши. Строки подходят, изменяемые списки — нет. Кортеж подходит, если хешируемы все его элементы.

Поиск в словаре в среднем занимает `O(1)`, но это не безусловная гарантия для любых ключей. Словарь сохраняет порядок вставки; сохранение порядка не означает сортировку.

Для частот и группировки есть готовые инструменты:

```python
from collections import Counter, defaultdict

visits = ["Анна", "Борис", "Анна", "Вера"]
print(Counter(visits).most_common(1))   # [('Анна', 2)]

groups = defaultdict(list)
for name in visits:
    groups[name[0]].append(name)
print(groups["А"])   # ['Анна', 'Анна']
```

`defaultdict(list)` вызывает `list` при первом обращении к отсутствующему ключу. Для разных ключей создаются разные списки.

## Множество отвечает на вопрос о принадлежности

Множество `set` хранит уникальные хешируемые элементы. Оно удобно для частых проверок принадлежности и сравнения групп, но не для восстановления порядка событий:

```python
yesterday = {"Анна", "Борис"}
today = {"Анна", "Вера"}
print(sorted(today & yesterday))   # ['Анна']: пересечение
print(sorted(today - yesterday))   # ['Вера']: разность
print(sorted(today | yesterday))   # ['Анна', 'Борис', 'Вера']
```

Сортировка нужна только для предсказуемого вывода. Само множество не хранит порядок первого появления. Если нужно убрать повторы, сохранив этот порядок, используйте `list(dict.fromkeys(visits))`.

## Преобразования и очередь

Включение, или comprehension, создаёт коллекцию из другой коллекции:

```python
amounts = [100, -20, 50, 0]
result = [amount * 2 for amount in amounts if amount > 0]
print(result)   # [200, 100]
```

Читайте выражение так: для каждой суммы проверить условие; если оно истинно, добавить удвоенную сумму. Несколько сложных вложенных циклов лучше записать обычным `for`. Круглые скобки вместо квадратных дадут генераторное выражение — ленивый источник значений, которому посвящён отдельный урок.

Для очереди, где добавляют справа и забирают слева, предназначен `deque`:

```python
from collections import deque

queue = deque(["первая", "вторая"])
queue.append("третья")
print(queue.popleft())   # первая
```

Удаление первого элемента списка требует сдвига ссылок. Очередь `deque` поддерживает операции с обоих концов без такого сдвига. Стек, где забирают последний добавленный элемент, удобно реализовать обычным списком с `append` и `pop`.

## Самопроверка и практика

1. Почему журнал событий нельзя без потерь заменить множеством?
2. Что произойдёт при повторном присваивании одного ключа?
3. Почему кортеж со списком внутри не годится ключом словаря?
4. Когда маленький список разумнее отдельного множества?

Разбор: множество теряет повторы и порядок; словарь заменяет значение; вложенный список не хешируем; построение дополнительной структуры требует затрат и может быть лишним ради одной проверки.

**Практика.** Для `["a", "b", "a", "c", "b", "a"]` получите число событий, число людей, частоты и уникальные имена в порядке первого появления. Ожидаются `6`, `3`, `{"a": 3, "b": 2, "c": 1}` и `["a", "b", "c"]`.

В визуализации сравните повторное добавление имени в список, множество и словарь. Для интервью объясняйте сохранённую информацию и стоимость нужной операции. Следующий шаг — оформить обработку коллекций в функции с ясным результатом.
