# Как Python работает с данными

Допустим, вы готовите список признаков для модели. Для эксперимента нужно добавить ещё один признак, сохранив исходный список. Вы пишете `experiment = features`, меняете `experiment` — и обнаруживаете изменение в `features`. Чтобы объяснить это поведение, начнём с того, что выполняет присваивание.

Код в этом уроке выполняется сверху вниз в Python 3. `print(...)` выводит результат. Текст после `#` — комментарий: Python его не выполняет. Кавычки ограничивают строку, квадратные скобки — список элементов. Это первые инструменты; сложный синтаксис пока не нужен.

## Значение, объект и имя

Число `10`, строка `"age"` и список `["age", "income"]` — объекты. У объекта есть тип, значение и идентичность. Тип определяет допустимые действия: числа складывают, строки соединяют, в список добавляют элементы.

Переменная — имя, ссылающееся на объект. Присваивание не копирует его содержимое:

```python
features = ["age", "income"]
experiment = features
experiment.append("city")
print(features)                # ['age', 'income', 'city']
print(experiment is features)   # True
```

Метод `append` добавляет элемент в существующий список. Оба имени указывают на него, поэтому изменение видно через оба имени. Представьте одну страницу с двумя закладками: вторая закладка не создаёт копию страницы.

Перепривязка имени — другое действие:

```python
features = ["age", "income"]
experiment = features
experiment = ["country"]
print(features)     # ['age', 'income']
print(experiment)   # ['country']
```

Последнее присваивание создало новый список и связало с ним только `experiment`. Имя `features` осталось связано с исходным списком.

## Равенство не означает идентичность

Оператор `==` сравнивает значения, а `is` проверяет, один ли это объект:

```python
left = [1, 2]
right = [1, 2]
alias = left
print(left == right)   # True
print(left is right)   # False
print(left is alias)   # True
```

Одинаково заполненные списки могут быть независимыми. Функция `id` возвращает идентификатор объекта, уникальный среди одновременно существующих объектов. Это инструмент исследования ссылок, а не постоянный номер записи.

Для чисел и строк сравнивайте значения через `==`. Интерпретатор может переиспользовать некоторые неизменяемые объекты, поэтому результаты `is` для маленьких чисел не следует обобщать. Типичный случай для `is` — `value is None`: `None` обозначает отсутствие значения.

## Что означает изменяемость

Списки, словари и множества изменяемы. Числа, строки и кортежи неизменяемы. Это свойство объекта, а не запрет присвоить переменной другое значение.

```python
name = "cat"
previous = name
name += "s"
print(name)       # cats
print(previous)   # cat
```

Получилась новая строка. Старая доступна через `previous`. Для списка операция `+=` обычно расширяет сам список: одинаковый символ операции не гарантирует одинакового поведения разных типов.

Кортеж хранит фиксированную последовательность ссылок. Заменить его элемент нельзя, но изменить вложенный список можно:

```python
record = ([10, 20], "train")
record[0].append(30)
print(record)   # ([10, 20, 30], 'train')
```

Кортеж сохранил состав ссылок. Изменился объект, находящийся по первой ссылке.

## Когда копия действительно независима

Для плоского списка строк достаточно `copy()`. Для вложенной структуры поверхностная копия создаёт новый внешний контейнер, но оставляет общие внутренние объекты.

```python
original = [[1], [2]]
shallow = original.copy()
shallow[0].append(3)
print(original)                   # [[1, 3], [2]]
print(shallow is original)         # False
print(shallow[0] is original[0])   # True
```

Если нужна независимость всей такой структуры, используют глубокое копирование:

```python
from copy import deepcopy

original = [[1], [2]]
independent = deepcopy(original)
independent[0].append(3)
print(original)   # [[1], [2]]
```

Глубокая копия расходует память и время. Она нужна по смыслу задачи, а не как обязательное действие перед каждым преобразованием.

Сходная ошибка возникает при создании матрицы:

```python
wrong = [[0] * 3] * 2
wrong[0][0] = 1
print(wrong)   # [[1, 0, 0], [1, 0, 0]]

right = [[0] * 3 for _ in range(2)]
right[0][0] = 1
print(right)   # [[1, 0, 0], [0, 0, 0]]
```

Первый вариант повторяет ссылку на одну строку. Во втором выражение создания строки выполняется два раза. Запись с `for` подробно изучим в следующем уроке.

## Как эта модель объясняет функции

Функция — именованный блок действий. При вызове её параметр становится локальным именем переданного объекта. Отступ обозначает действия внутри функции.

```python
def append_city(items):
    items.append("city")

def replace_items(items):
    items = ["country"]
    return items

features = ["age"]
append_city(features)
replacement = replace_items(features)
print(features)      # ['age', 'city']
print(replacement)   # ['country']
```

Первая функция изменила общий объект. Вторая перепривязала только своё локальное имя и вернула новый список.

Значение параметра по умолчанию вычисляется один раз при определении функции. Поэтому `users=[]` создаст общий список для будущих вызовов. Исправление:

```python
def add_user(name, users=None):
    if users is None:
        users = []
    users.append(name)
    return users

print(add_user("Анна"))    # ['Анна']
print(add_user("Борис"))   # ['Борис']
```

Здесь новый список создаётся внутри вызова. Если же намеренно передать существующий список, функция изменит его. Детали объявления и вызова функций разберём отдельно; сейчас важно увидеть единую модель ссылок.

## Самопроверка и практика

1. Почему после `b = a` нужно знать следующую операцию, чтобы предсказать изменение `a`?
2. Как разные внешние списки могут иметь общие данные?
3. Почему `is` и `==` отвечают на разные вопросы?
4. Почему список в параметре по умолчанию сохраняется между вызовами?

Разбор: мутация общего объекта отличается от перепривязки имени; поверхностная копия сохраняет внутренние ссылки; равенство значений не означает идентичности; значение по умолчанию создаётся при определении функции.

**Практика.** Создайте две независимые строки по три нуля. Поменяйте последний элемент второй строки на `5`. Ожидаемый результат: `[[0, 0, 0], [0, 0, 5]]`. Сделайте глубокую копию и проверьте, что изменение копии не меняет оригинал.

В интерактивной схеме проследите, когда меняется существующий объект и когда создаётся новый. На собеседовании объясняйте поведение через ссылки и конкретные действия. Это пригодится при выборе коллекции, передаче данных в функции и работе с таблицами.
