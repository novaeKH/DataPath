# Собственные векторы: направления, которые преобразование сохраняет

После применения матрицы большинство векторов меняет и длину, и направление. Но некоторые особые направления остаются на той же прямой. Их изучение помогает понять геометрию преобразования, устойчивость вычислений и главные компоненты данных.

Начнём с растяжения плоскости. Важна не магия новой формулы, а вопрос: какой вектор после действия матрицы превратится в собственную кратную копию?

## Определение через проверяемое действие

Для матрицы $A$ ненулевой вектор $v$ называется собственным, если

$$
Av=\lambda v.
$$

Число $\lambda$ — собственное значение. Оно показывает масштаб изменения: значение 2 удваивает длину, $-1$ меняет направление на противоположное, 0 превращает вектор в нулевой. Нулевой вектор исключён из определения, иначе равенство было бы тривиальным для любого числа.

Возьмём $A=\operatorname{diag}(2,1)$. Горизонтальный вектор $(1,0)$ превращается в $(2,0)$: это собственное направление со значением 2. Вертикальный $(0,1)$ остаётся прежним: значение 1.

Вектор $(1,1)$ превращается в $(2,1)$, то есть обычно меняет направление. Он не собственный для этой матрицы. Любой ненулевой кратный собственного вектора также собственный; речь идёт о направлении, а не об одной длине стрелки.

## Числовая проверка в NumPy

```python
import numpy as np

A = np.array([[2., 1.], [1., 2.]])
values, vectors = np.linalg.eigh(A)
print(values)   # [1. 3.]

v = vectors[:, -1]
print(np.allclose(A @ v, values[-1] * v))   # True
```

`eigh` предназначен для вещественных симметричных или комплексных эрмитовых матриц. Столбцы результата — собственные векторы, соответствующие значениям. В этом примере направления пропорциональны $(1,-1)$ и $(1,1)$.

Знак вектора может отличаться между вычислениями: $v$ и $-v$ задают одну прямую. Это не ошибка. Сравнивайте действие и направление, а не требуйте совпадения знака каждой координаты.

Для общей матрицы используется другой решатель; собственные значения могут быть комплексными. Не переносите свойства симметричных матриц на любые матрицы без проверки.

## Почему симметричные матрицы удобны

У вещественной симметричной матрицы собственные значения вещественны, а собственные векторы можно выбрать ортонормированными. Это означает взаимно перпендикулярные направления единичной длины.

Тогда преобразование можно понять как переход в эти координаты, масштабирование по каждой оси и обратный переход. Вместо большого набора смешанных коэффициентов мы видим независимые направления действия.

Если собственное значение повторяется, соответствующее пространство может иметь несколько равноценных базисов. Отдельные векторы внутри него не обязаны быть единственными. Это объясняет, почему при почти равных значениях направления могут заметно поворачиваться от небольшого изменения данных.

## Связь с ковариацией и PCA

Ковариационная матрица описывает совместное изменение числовых признаков после вычитания средних. Определение ковариации разберём в вероятностном блоке; здесь достаточно интуиции: матрица показывает, в каких направлениях облако данных вытянуто сильнее.

У ковариационной матрицы собственный вектор задаёт направление, а собственное значение — дисперсию проекций на это направление. PCA выбирает направления с наибольшей дисперсией.

Если значения равны 9 и 1, первое направление объясняет (9/(9+1)=0.9), или 90% суммарной дисперсии. Это не означает 90% качества предсказания цели: PCA ничего не знает о цели. Небольшое по дисперсии направление может быть важным для классификации.

## Что следует проверять в данных

Масштаб признаков меняет ковариацию, а значит и направления. Если один столбец измеряется в тысячах, он может определять главную компоненту. Решение о стандартизации зависит от смысла единиц и задачи.

Для численного PCA часто используют сингулярное разложение исходной центрированной матрицы. Оно связано с собственными направлениями, но позволяет не строить ковариационную матрицу явно. Формулы SVD не обязательны для первого понимания PCA; важно знать, что библиотечная реализация не обязана буквально повторять учебный способ.

## Самопроверка и практика

1. Почему нулевой вектор исключён из определения?
2. Что означает отрицательное собственное значение?
3. Почему смена знака собственного вектора не меняет компоненту?
4. Почему большая дисперсия не гарантирует полезность для цели?

Разбор: иначе равенство не выделяет направление; действие меняет ориентацию; прямая остаётся той же; дисперсия относится к признакам, а не к качеству прогноза.

**Практика.** Для $A=\operatorname{diag}(3,2)$ проверьте векторы $(1,0)$, $(0,1)$ и $(1,1)$. Первые два — собственные со значениями 3 и 2, третий — нет. Затем объясните, что изменится у матрицы $3I$: любое ненулевое направление будет собственным.

В визуализации поворачивайте вектор и ищите положения, где преобразованная стрелка остаётся на той же прямой. В уроке PCA эта идея станет методом уменьшения размерности.
