# Матричные операции, линейные преобразования, ранг и системы уравнений

Матрица — не просто таблица чисел. Она задаёт линейное преобразование: поворот, растяжение, проекцию или смешивание признаков. Понимание rank и систем уравнений объясняет мультиколлинеарность и устойчивость линейной регрессии.

## Matrix multiplication

Если \(A\in R^{m\times n}\) и \(B\in R^{n\times k}\), то \(AB\in R^{m\times k}\). Внутренние dimensions должны совпасть. Matrix multiplication — композиция линейных преобразований.

## Транспонирование

\(A^T\) меняет rows/columns. В линейной регрессии \(X^TX\) — matrix попарных dot products columns. Это связывает algebra с correlation/multicollinearity.

## Линейное преобразование

\(y=Ax\). Columns A показывают, куда отправляются basis vectors. Если несколько input directions схлопываются в одну, information теряется.

## Rank

Rank — число линейно независимых направлений/columns (эквивалентно rows). Rank < number of columns означает линейную зависимость признаков: один может выражаться через другие.

## Система Ax=b

Unique solution требует достаточной независимости. Если equations redundant, решений может быть бесконечно много; если inconsistent — ни одного. Least squares выбирает приближённое решение, минимизируя residual norm.

## Обратная матрица и псевдообратная

Не надо вычислять inverse вручную для ML-кода. Численные библиотеки используют устойчивые decompositions/solvers. Псевдообратная позволяет формулировать least-squares решение даже при не-square/singular cases.

## Пошаговый пример: матрица как преобразование

Возьмём вектор (x=(2, 1)) и матрицу

$$
A=\begin{pmatrix}2&0\\0&1\end{pmatrix}.
$$

Произведение (Ax=(4,1)): первая координата растянулась вдвое, вторая сохранилась. Матрица — не просто таблица чисел, а правило, которое переводит входной вектор в новый. Если после этого применить другую матрицу (B), итог (B(Ax)) равен ((BA)x); порядок умножения соответствует порядку преобразований справа налево.

Ранг показывает число независимых направлений, которые преобразование сохраняет. Матрица, переводящая все точки плоскости на одну прямую, имеет ранг 1: одна степень свободы потеряна. Поэтому система уравнений может не иметь единственного решения, а признаки с точной линейной зависимостью не добавляют независимой информации.

Обратная матрица существует только для квадратной невырожденной матрицы. В вычислениях обычно не строят `inv(A) @ b`, а решают систему через `solve`: так точнее и понятнее выражено намерение. Если задача плохо обусловлена, малая ошибка во входе может сильно изменить решение — это подводит к регуляризации и устойчивым численным методам.

```python
import numpy as np

A = np.array([[1., 2.], [3., 4.]])
b = np.array([5., 11.])

x = np.linalg.solve(A, b)

X = np.array([[1., 1.],
              [2., 2.],
              [3., 3.]])
print(np.linalg.matrix_rank(X))  # 1, columns dependent
```

## Типичные ошибки

- путать elementwise и matrix multiplication
- считать inverse лучшим способом решать системы
- думать, что много признаков означает высокий rank
- игнорировать nearly dependent columns
- считать singularity только теоретической проблемой

## Мини-практика

Создайте X с тремя признаками, где третий равен сумме первых двух. Найдите rank и объясните, почему коэффициенты линейной модели могут быть нестабильными.

## Что нужно унести

Matrix algebra описывает, сколько независимой информации содержат признаки и как модели преобразуют пространство. Rank — ключ к пониманию redundancy.
