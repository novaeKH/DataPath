# Матричные операции: преобразование, ранг и решение системы

Вектор описывает объект, а матрица может описывать действие над ним. Например, двумерную точку можно растянуть по одной оси, повернуть или спроецировать на прямую. Та же запись используется для слоя нейросети и системы линейных уравнений.

Начнём с преобразования, у которого легко проверить результат вручную. Затем выясним, почему некоторые преобразования можно обратить, а другие теряют информацию.

## Матрица действует на вектор

$$
A = \begin{pmatrix}2&0\\0&3\end{pmatrix},
\qquad x = \begin{pmatrix}1\\2\end{pmatrix},
\qquad Ax = \begin{pmatrix}2\\6\end{pmatrix}.
$$

Первая координата умножилась на два, вторая — на три. В общем случае каждая строка матрицы задаёт взвешенную сумму входных координат. Матрица формы $m\times d$ превращает вектор из $d$ чисел в вектор из $m$ чисел.

```python
import numpy as np

A = np.array([[2., 0.], [0., 3.]])
x = np.array([1., 2.])
print(A @ x)   # [2. 6.]
```

Это линейное преобразование: преобразование суммы равно сумме преобразований, а масштабирование входа переносится на результат. Добавление отдельного смещения даёт аффинное преобразование, как в обычном линейном слое с bias.

## Произведение матриц — последовательность действий

Если сначала применить $B$, затем $A$, получится $A(Bx)=(AB)x$. Читаем композицию справа налево. Внутренние размеры должны совпадать: $(m,d)@(d,k)\rightarrow(m,k)$.

Порядок обычно важен. Сначала повернуть изображение, затем растянуть горизонтально — не то же самое, что сначала растянуть, затем повернуть. Поэтому $AB$ и $BA$ могут отличаться или одно из произведений вообще не иметь подходящей формы.

Транспонирование меняет местами строки и столбцы. Для произведения действует правило $(AB)^T=B^TA^T$: порядок также меняется. В ML транспонирование помогает перейти от представления «строки — объекты» к вычислению связей между признаками.

## Ранг показывает число независимых направлений

Рассмотрим матрицу:

$$
C=\begin{pmatrix}1&2\\2&4\end{pmatrix}.
$$

Вторая строка удвоена относительно первой. Два уравнения не дают двух независимых ограничений. Ранг равен одному: преобразование сохраняет только одно независимое направление информации.

В таблице признаков похожая ситуация возникает, когда один столбец является точной комбинацией других. Например, общая сумма равна сумме двух её частей. Модель может давать одинаковые прогнозы при разных коэффициентах, потому что данные не различают некоторые наборы весов.

Почти зависимые столбцы не обязательно уменьшают формальный ранг, но делают задачу неустойчивой: небольшое изменение данных может сильно изменить коэффициенты.

## Решение системы и обратная матрица

Пусть $Aw=b$. Нужно найти неизвестные коэффициенты $w$, которые дают наблюдаемые значения $b$. Если квадратная матрица обратима, решение единственно и символически записывается $w=A^{-1}b$.

Для вычисления обычно используйте решатель, а не явное построение обратной матрицы:

```python
A = np.array([[2., 1.], [1., -1.]])
b = np.array([5., 1.])
w = np.linalg.solve(A, b)
print(w)        # [2. 1.]
print(A @ w)    # [5. 1.]
```

Первое уравнение: $2\cdot2+1=5$. Второе: $2-1=1$. Проверка подстановкой помогает увидеть смысл результата. `solve` предназначен для квадратной системы с подходящими свойствами; если независимых ограничений недостаточно, единственного решения может не быть.

Обратимость означает, что преобразование не потеряло информацию. Проекцию на прямую обратить для произвольной исходной точки нельзя: множество точек имеют одну и ту же проекцию.

## Когда уравнения не согласованы

В данных наблюдения содержат шум. Уравнений может быть больше, чем неизвестных, и точного решения нет. Тогда ищут веса, которые минимизируют суммарную квадратичную невязку:

```python
X = np.array([[1., 1.], [1., 2.], [1., 3.]])
y = np.array([2., 3., 5.])
weights, residuals, rank, singular_values = np.linalg.lstsq(X, y, rcond=None)
print(np.round(weights, 3))   # [0.333 1.5]
print(np.round(X @ weights, 3))   # [1.833 3.333 4.833]
```

Первый столбец единиц отвечает за свободный член, второй — за наклон. Точные наблюдения не воспроизводятся, но найден лучший компромисс по выбранной квадратичной ошибке. Это прямой мост к линейной регрессии.

## Самопроверка и практика

1. Почему порядок двух матричных преобразований важен?
2. Что означает зависимость строк для информации в системе?
3. Почему проекция может не иметь обратного преобразования?
4. Зачем проверять найденные веса подстановкой?

Разбор: действия обычно не перестановочны; часть ограничений повторяется; разные входы дают один выход; подстановка подтверждает смысл решения и обнаруживает ошибки формы.

**Практика.** Измените вторую строку матрицы первого решателя на удвоенную первую, а правую часть — соответственно. Объясните, почему теперь нельзя получить единственное решение только из этих двух уравнений. Не заменяйте ошибку решателя случайным регуляризатором, пока не поняли причину.

В визуализации сравните растяжение и проекцию. Далее разберём направления, которые матрица сохраняет при преобразовании.
