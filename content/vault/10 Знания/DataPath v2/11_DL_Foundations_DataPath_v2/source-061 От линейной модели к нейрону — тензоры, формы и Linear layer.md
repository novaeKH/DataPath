# От линейной модели к нейрону: тензоры и формы

Линейная модель умножает признаки на веса и складывает результаты. Нейрон начинает с того же вычисления, но может применить к сумме нелинейную функцию. Нейронная сеть соединяет много таких преобразований и обучает их параметры совместно.

Перед архитектурами нужно уверенно читать формы тензоров. Многие ошибки нейросетей возникают не в сложной математике, а в перепутанной оси объектов или признаков.

## Тензор как массив с несколькими осями

В практическом PyTorch тензор похож на массив NumPy: имеет форму, тип и данные. Он также может находиться на CPU или ускорителе и участвовать в автоматическом вычислении производных.

Скаляр имеет форму `()`, вектор — `(d,)`, пакет объектов — `(B, d)`. Здесь `B` — размер пакета, `d` — число признаков. Пакет позволяет обрабатывать несколько примеров одним матричным вычислением.

```python
import torch

X = torch.tensor([[1., 2.], [3., 4.]])
print(X.shape)   # torch.Size([2, 2])
print(X.dtype)   # torch.float32
print(X.device)  # cpu
```

Тип и устройство входа должны быть совместимы с параметрами модели. Целочисленные индексы токенов и вещественные признаки выполняют разные роли; преобразование всех входов в один тип без понимания часто ошибочно.

## Один нейрон вручную

Пусть вход $x=(1,2)$, веса $w=(0.5,-1)$, смещение $b=1$. Линейная сумма равна $z=1\cdot0.5+2\cdot(-1)+1=-0.5$. После ReLU получится ноль: эта функция оставляет положительные значения и заменяет отрицательные нулём.

```python
x = torch.tensor([1., 2.])
w = torch.tensor([0.5, -1.])
b = torch.tensor(1.)
z = x @ w + b
output = torch.relu(z)
print(z.item(), output.item())   # -0.5 0.0
```

Смещение позволяет сдвинуть границу реакции нейрона независимо от признаков. Веса определяют вклад координат. Значение нейрона не обязано быть вероятностью: смысл выхода зависит от последнего слоя и задачи.

## Linear вычисляет несколько выходов

Слой `nn.Linear(d, h)` получает последнюю ось размера `d` и выдаёт последнюю ось размера `h`. Для пакета форма меняется с `(B,d)` на `(B,h)`.

```python
from torch import nn

layer = nn.Linear(2, 3)
Y = layer(X)
print(layer.weight.shape)   # torch.Size([3, 2])
print(layer.bias.shape)     # torch.Size([3])
print(Y.shape)              # torch.Size([2, 3])
```

В PyTorch веса хранятся в форме `(out_features, in_features)`, поэтому математически слой вычисляет `X @ weight.T + bias`. У каждого из трёх выходов своя пара весов и своё смещение: всего девять обучаемых чисел.

Создание слоя инициализирует параметры, но не обучает их. Случайный вывод — результат текущих весов, а не осмысленный прогноз.

## Форма может быть допустимой и неверной по смыслу

Если целевые значения имеют форму `(B,)`, а прогнозы — `(B,1)`, некоторые поэлементные операции через broadcasting создадут матрицу `(B,B)`. Код может выполниться, сравнив каждый прогноз с каждой целью.

Перед потерей явно сопоставьте формы. Если нужна одна цель на объект, используйте согласованные `(B,1)` или уберите только последнюю ось через `squeeze(-1)`. Безусловный `squeeze()` может удалить ось пакета, когда в пакете один объект.

`reshape` меняет форму, а `transpose` и `permute` переставляют оси. Они не взаимозаменяемы. Для изображений нужно знать, какая ось обозначает каналы, высоту и ширину.

## Где начинается обучение

Параметры слоя зарегистрированы в объекте `nn.Module`. Их можно получить через `parameters()` и передать оптимизатору. Во время прямого прохода PyTorch строит граф операций, если требуется вычислять производные.

Пока достаточно разделить три действия: вычислить выход, сравнить его с целью, изменить параметры. Вызов `layer(X)` выполняет только первое. Функцию потерь разберём дальше, а вычисление градиентов — в отдельном уроке.

## Самопроверка и практика

1. Сколько параметров у `Linear(4, 2)` со смещением?
2. Почему выход линейного слоя не обязательно вероятность?
3. Чем опасны формы `(B,)` и `(B,1)` в одной потере?
4. Почему создание слоя не является обучением?

Разбор: восемь весов и два смещения; диапазон не ограничен; broadcasting может сравнить лишние пары; параметры лишь инициализированы.

**Практика.** Измените в ручном нейроне смещение с 1 до 2. Сумма станет 0.5, ReLU тоже вернёт 0.5. Затем создайте пакет из двух входов и вычислите оба результата одной операцией.

На иллюстрации проследите путь каждого входа до суммы. В интерактивном нейроне меняйте один параметр за раз и предсказывайте знак выхода до движения ползунка. Дальше соединяем нейроны в сеть.
