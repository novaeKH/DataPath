# Доверительный интервал: показываем неопределённость оценки

Средний чек выборки равен 1200. Это число полезно, но не показывает, насколько оно устойчиво. Среднее по десяти заказам и по десяти тысячам заказов имеют разную неопределённость.

Доверительный интервал добавляет диапазон, построенный по правилу с известными свойствами при повторном сборе данных. Для понимания важнее смысл процедуры и её предположения, чем механическое применение числа 1.96.

## Параметр, оценка и стандартная ошибка

Параметр — неизвестное свойство распределения, например истинное среднее $\mu$. Оценка — число, вычисленное по выборке, например $\bar x$. Стандартная ошибка характеризует разброс этой оценки между повторными выборками.

Для независимых наблюдений стандартную ошибку среднего оценивают как $s/\sqrt n$, где $s$ — выборочное стандартное отклонение. Не путайте её со стандартным отклонением отдельных значений: первое описывает оценку среднего, второе — разнообразие самих заказов.

При большом объёме и подходящих условиях приближённый интервал имеет вид

$$
\bar x\pm1.96\frac{s}{\sqrt n}.
$$

Если средний чек 1200, $s=300$, $n=100$, стандартная ошибка равна 30, а границы — примерно 1141.2 и 1258.8.

## Как правильно читать 95%

В частотной интерпретации неизвестный параметр фиксирован. Случайным является интервал, потому что меняются данные. Если многократно применять корректную процедуру, примерно 95% построенных интервалов будут покрывать параметр.

Это не означает, что 95% отдельных заказов находятся внутри интервала среднего. Для отдельных наблюдений нужен другой, обычно более широкий диапазон. Это также не означает автоматическую вероятность 95% для параметра после наблюдения конкретного интервала; такая формулировка относится к другой, байесовской конструкции.

## Интервал с распределением Стьюдента

Когда стандартное отклонение неизвестно и оценивается по выборке, для независимой нормальной выборки используют распределение Стьюдента. Оно учитывает дополнительную неопределённость.

```python
import numpy as np
from scipy import stats

values = np.array([10., 12., 9., 11., 13.])
n = len(values)
mean = values.mean()
se = values.std(ddof=1) / np.sqrt(n)
critical = stats.t.ppf(0.975, df=n - 1)
lower, upper = mean - critical * se, mean + critical * se
print(round(mean, 2), round(lower, 2), round(upper, 2))
# 11.0 9.04 12.96
```

`ddof=1` использует знаменатель $n-1$ при оценке дисперсии. `ppf(0.975)` даёт границу, оставляющую 2.5% вероятности справа; ещё 2.5% остаётся слева. Для маленькой выборки критическое значение больше 1.96.

Этот расчёт не отменяет предположений о данных. Пять сильно зависимых или крайне асимметричных наблюдений не становятся надёжной основой только из-за использования t-распределения.

## Bootstrap: повторная выборка из наблюдаемого

Bootstrap приближает неопределённость, многократно выбирая наблюдения с возвращением из имеющейся выборки и пересчитывая показатель.

```python
rng = np.random.default_rng(42)
samples = rng.choice(values, size=(5000, len(values)), replace=True)
estimates = samples.mean(axis=1)
print(np.quantile(estimates, [0.025, 0.975]))
```

Повторное появление наблюдения допустимо: это часть процедуры. Границы квантилей дают простой процентильный интервал. Bootstrap не является универсальным спасением для малых, зависимых или смещённых данных; он переиспользует то, что было наблюдено.

Если единица независимости — пользователь, нужно переотбирать пользователей, а не отдельные события. Для временных рядов могут понадобиться блоки, сохраняющие зависимость.

## Уровень доверия, ширина и полезность

Более высокий уровень доверия обычно расширяет интервал. Большая выборка при сопоставимом разбросе сужает его. Уменьшение систематической ошибки требует улучшения источника или дизайна, а не просто более узкой формулы.

Для сравнения моделей полезно оценивать разность метрик на согласованных наблюдениях. Если модели проверяются на одних объектах, разность имеет парную структуру; независимые интервалы каждой метрики могут терять эту информацию.

Практический вывод должен учитывать масштаб. Интервал улучшения выручки от 0.01% до 0.02% может быть статистически определённым, но не покрывать стоимость внедрения.

## Самопроверка и практика

1. Почему интервал среднего не покрывает 95% отдельных заказов?
2. Что случайно в частотной процедуре?
3. Почему bootstrap не создаёт отсутствующие типы клиентов?
4. Что произойдёт с шириной при переходе от 95% к 99%?

Разбор: оценивается среднее, а не разброс наблюдений; выборка и построенные по ней границы; переотбираются только наблюдённые данные; при прочих равных интервал станет шире.

**Практика.** Для $s=300$ увеличьте объём с 100 до 400. Стандартная ошибка уменьшится с 30 до 15, приближённая половина ширины 95%-интервала — с 58.8 до 29.4. Объясните, почему это ничего не говорит об исправлении неверного отбора клиентов.

В визуализации наблюдайте серию повторно построенных интервалов. Следующий урок свяжет неопределённость с проверкой гипотез.
