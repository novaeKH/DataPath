# NumPy: форма массива и смысл осей

Пусть у трёх квартир известны площадь и число комнат. В Python можно хранить список списков, но для тысяч одинаковых вычислений удобнее числовой массив. NumPy хранит однотипные значения в буфере и выполняет операции над целыми массивами.

Перед быстрым вычислением нужно договориться о смысле формы. В нашем примере строки — квартиры, столбцы — признаки. Перепутанные оси могут дать допустимый код и неправильный ответ.

## Создаём массив и читаем форму

```python
import numpy as np

X = np.array([[30, 1], [50, 2], [80, 3]], dtype=np.float64)
print(X.shape)   # (3, 2)
print(X.ndim)    # 2
print(X.dtype)   # float64
print(X.size)    # 6
```

`shape` содержит размеры по осям: три строки и два столбца. `ndim` — число осей, `size` — общее число элементов. `dtype` определяет представление каждого элемента, здесь 64-битное число с плавающей точкой.

Массив формы `(3,)` имеет одну ось. Он не то же самое, что столбец `(3, 1)` или строка `(1, 3)`. Различие понадобится при broadcasting и матричном умножении.

Тип влияет на память и арифметику. Целочисленный массив не начинает автоматически хранить произвольные дроби при присваивании. Числа ограниченной разрядности могут переполниться. Выбирайте тип по диапазону и точности данных, а не только по минимальному размеру.

## Индексы выбирают данные, срезы могут разделять память

```python
print(X[1, 0])     # 50.0
print(X[:, 0])    # [30. 50. 80.]
print(X[:2, :])   # первые две квартиры

view = X[:2, :]
view[0, 0] = 31
print(X[0, 0])    # 31.0
```

Запись `:` выбирает всю соответствующую ось. Обычный срез часто возвращает представление: новый объект массива использует тот же буфер. Поэтому изменение `view` видно в `X`. Для независимости используйте `X[:2, :].copy()`.

Выбор по списку индексов и булевой маске относится к расширенной индексации и создаёт копию. Не переносите на NumPy правило «любой срез — независимый список» из Python: здесь другое устройство хранения.

## axis означает, какое измерение сворачивается

Вернём исходные данные:

```python
X = np.array([[30., 1.], [50., 2.], [80., 3.]])
print(X.mean(axis=0))   # [53.33333333  2.        ]
print(X.sum(axis=1))    # [31. 52. 83.]
print(X.mean())        # 27.666666666666668
```

При `axis=0` сворачивается ось квартир: для каждого столбца остаётся среднее по трём строкам. Это осмысленные средняя площадь и среднее число комнат. При `axis=1` складываются признаки внутри квартиры. Арифметически операция верна, но сумма площади и количества комнат обычно не имеет полезного смысла.

Без `axis` сворачиваются все элементы. Хорошая привычка — до вычисления произнести, какие объекты должны остаться в результате. `keepdims=True` сохраняет свёрнутую ось длины один; это удобно для последующего вычитания среднего.

## Поэлементные и матричные операции

```python
areas = X[:, 0]
print(areas / 10)   # [3. 5. 8.]

weights = np.array([2., 10.])
print(X @ weights)  # [ 70. 120. 190.]
```

Деление применилось к каждому элементу. Оператор `@` выполнил скалярное произведение каждой строки с весами: для первой квартиры `30*2 + 1*10 = 70`. Оператор `*` означает поэлементное умножение, а не матричное.

Векторизация переносит цикл из пользовательского Python-кода в операции библиотеки. Она часто ускоряет работу, но сложное выражение может создавать большие временные массивы. `np.vectorize` само по себе не превращает произвольную Python-функцию в быстрый численный алгоритм.

## Изменение формы и устройство памяти

`reshape` меняет представление формы, сохраняя число элементов и выбранный порядок чтения. Из шести значений можно получить `(3, 2)` или `(2, 3)`, но не `(4, 2)`. Параметр `-1` позволяет вычислить один размер автоматически.

`reshape` не заменяет транспонирование. `X.T` меняет местами оси, а `reshape` перераспределяет последовательность элементов по новой форме. В задачах с изображениями случайная замена одной операции другой перемешивает смысл координат.

`strides` указывает смещения в байтах при переходе по осям. Представление транспонированного массива может использовать другой порядок обхода того же буфера. Поэтому не всякий массив непрерывен в памяти и не всякое изменение формы обходится без копии.

## Самопроверка и практика

1. Почему формы `(3,)` и `(3, 1)` различаются?
2. Почему сумма признаков квартиры может быть бессмысленной при корректной форме?
3. Когда изменение среза меняет исходный массив?
4. Чем `*` отличается от `@`?

Разбор: различается число осей; форма не содержит единицы измерения; представление разделяет буфер; операции выполняют разные математические действия.

**Практика.** Создайте массив `[[10, 100], [20, 200], [30, 300]]`. До запуска предскажите средние по `axis=0`, по `axis=1` и форму обоих результатов. Ответы: `[20, 200]`, `[55, 110, 165]`, формы `(2,)` и `(3,)`.

В визуализации переключайте ось и следите, какие клетки объединяются. Следующий урок объяснит, как вычесть отдельное среднее из каждого столбца без ручного цикла.
