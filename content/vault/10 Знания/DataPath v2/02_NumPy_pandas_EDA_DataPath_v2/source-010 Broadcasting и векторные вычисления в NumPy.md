# Broadcasting и векторные вычисления в NumPy

Broadcasting позволяет записать стандартизацию как `(X - mean) / std`, хотя `X` имеет форму `(n, d)`, а `mean/std` — `(d,)`. Это ключевой механизм NumPy и источник многих shape-bugs.

## Правило совместимости

Размерности сравниваются справа налево. Они совместимы, если равны или одна из них равна 1. Отсутствующая ведущая ось мысленно считается 1. Поэтому `(1000, 20)` и `(20,)` совместимы, а `(1000, 20)` и `(1000,)` — нет.

## Добавление оси

`v[:, None]` превращает `(n,)` в `(n,1)`, а `v[None, :]` — в `(1,n)`. Это не ручное копирование значений, а изменение представления формы.

## Boolean vectorization

Для массивов используют `&`, `|`, `~`, а не Python `and/or`. Каждое условие оборачивают в скобки: `(x > 0) & (x < 10)`.

## Матричное и поэлементное умножение

`A * B` — поэлементно; `A @ B` — matrix multiplication. Для ML это принципиально: `(n,d) @ (d,k) -> (n,k)`.

## Цена векторизации

Pairwise broadcasting `X[:,None,:] - Y[None,:,:]` удобно, но создаёт массив `(n,m,d)`. При больших n и m это может быть намного дороже Python-цикла с chunking. Векторизация — не магическая бесплатная память.

## Пошаговый пример: центрирование матрицы

Пусть `X` имеет форму `(3, 2)`: три объекта и два признака. Среднее по столбцам `mu = X.mean(axis=0)` имеет форму `(2,)`. При вычислении `X - mu` NumPy сравнивает формы справа налево: последние размеры равны двум, а отсутствующая ведущая ось у `mu` мысленно считается единицей. Вектор средних как будто повторяется для каждой строки, хотя полноценная матрица копий не создаётся.

Для среднего по строкам нужна другая форма. `X.mean(axis=1)` возвращает `(3,)`, и вычесть такой вектор из `(3, 2)` нельзя: справа сталкиваются размеры `2` и `3`. Вариант `X.mean(axis=1, keepdims=True)` сохраняет исчезающую ось и даёт `(3, 1)`. Теперь единичный второй размер можно расширить до двух столбцов.

Полезный порядок рассуждения таков: сначала записать формы операндов, затем выровнять их справа, после чего проверить каждую пару размеров. Только потом стоит запускать выражение. Это быстрее, чем угадывать расположение `None` экспериментами, и тот же приём работает с тензорами PyTorch.

Следите и за числом элементов результата. Выражение может быть корректным по правилам broadcasting, но создать промежуточный массив на десятки гигабайт. Корректная форма ещё не означает приемлемую стоимость.

## Практический код

```python
import numpy as np

X = np.random.randn(1000, 20)
mu = X.mean(axis=0)
sigma = X.std(axis=0)

X_scaled = (X - mu) / sigma

row_bias = np.arange(1000)[:, None]
Y = X + row_bias
```

## Типичные ошибки

- считать `(n,)` column vector
- использовать `and/or` на ndarray
- путать `*` и `@`
- забывать скобки в boolean mask
- создавать O(n²) broadcast-массив без оценки памяти
