# 02. Array, String и Sorting

[[01_Big_O|← Предыдущий]] · [[03_Hash_Map_и_Frequency_Map|Следующий →]]

## 1. Цель урока

Уверенно обходить последовательности, различать подмассив и подпоследовательность, выбирать in-place или новый результат и сортировать по ключу.

## 2. Главная идея

В Python алгоритмический array обычно представлен `list`. Непрерывный фрагмент — `nums[left:right + 1]`; подпоследовательность может пропускать элементы. Строка неизменяема.

## 3. Как распознать

Индексы, пары соседей, диапазон, строковые символы, «отсортируйте», «k-й по порядку», «in-place».

## 4. Когда не подходит

Если нужен быстрый membership — set; частые операции слева — deque; Top-K — heap; непрерывное окно без копий — индексы.

## 5. Необходимый Python

`enumerate`, `zip(..., strict=True)`, `sorted(key=...)`, `list.sort()`, `"".join`, срезы. Сортировка Python стабильна и имеет O(n log n) в худшем случае.

## 6. Универсальный шаблон

```python
def adjacent_differences(values: list[int]) -> list[int]:
    return [right - left for left, right in zip(values, values[1:])]
```

Срез `values[1:]` добавляет O(n) памяти. Для O(1) дополнительной памяти используйте индексы.

## 7. Первая задача: сортировка записей

```python
def rank(rows: list[tuple[str, float]]) -> list[tuple[str, float]]:
    return sorted(rows, key=lambda row: (-row[1], row[0]))

assert rank([("b", 0.8), ("a", 0.8)]) == [("a", 0.8), ("b", 0.8)]
```

Время O(n log n), память O(n) для результата.

## 8. Вторая задача: сборка строки

Удалить пробелы и привести слова к одной строке. Сначала соберите части, затем `join`; не наращивайте строку в цикле.

## 9. Третья задача без решения

LC 169 Majority Element: найдите элемент, встречающийся чаще `n/2`. Условие и тесты: [[01_Hash_Map_и_массивы_задачи#LC 169 — Majority Element]]. Подсказки и полное решение разнесены.

## 10. Трассировка

| исходная запись | key | порядок |
|---|---|---:|
| `("b", .8)` | `(-.8, "b")` | 2 |
| `("a", .8)` | `(-.8, "a")` | 1 |

## 11. Инвариант

При линейном обходе префикс до текущего индекса уже обработан; при сортировке результат упорядочен по заданному key.

## 12. Сложность

Один проход O(n), сортировка O(n log n), срез длины k O(k), конкатенация неизменяемых строк в цикле может дать O(n²).

## 13. Типичные ошибки

- путать subarray и subsequence;
- менять вход без разрешения;
- использовать `sort()` как возвращаемое значение;
- забывать стоимость среза;
- сортировать ради одного min/max;
- строить строку через `+=` в большом цикле.

## 14. Что сказать интервьюеру

> Я сохраняю порядок данных и прохожу последовательность один раз. Если нужна сортировка, использую стабильный `sorted` с явным key; это O(n log n). Для одного экстремума предпочту `min/max(key=...)` за O(n).

## 15. Мини-контрольная

Что возвращает `sort`? Зачем стабильность? Сложность slice? Когда heap лучше сортировки? Почему string immutable?

<details><summary>Ответы</summary>
`None`; сохраняет порядок равных ключей; O(k); когда нужен малый Top-K/поток; изменения создают новый объект.
</details>

## 16. Практика

Обязательное: 169, затем задачи Two Pointers. Дополнительно: 53 после [[17_Greedy]]. Повтор: пересказать различие in-place/новый объект.

## 17. Шпаргалка

Индекс O(1); membership list O(n); sort O(n log n); slice O(k); `join` для большого числа строк.

## Где это встречается в Data Science

Ранжирование моделей/признаков, нормализация строковых полей, линейная обработка записей. Для численных массивов сравнивайте с NumPy, но сначала понимайте стоимость базовых операций.
