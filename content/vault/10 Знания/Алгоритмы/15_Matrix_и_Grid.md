# 15. Matrix и Grid

[[14_Trees_BFS_DFS|← Предыдущий]] · [[16_Graphs|Следующий →]]

## 1. Цель урока

Обходить матрицу как неявный граф и не выходить за границы.

## 2. Главная идея

Каждая клетка — вершина, допустимые соседние клетки — рёбра.

## 3. Как распознать

Острова, заливка, распространение, компоненты, кратчайшее расстояние по клеткам.

## 4. Когда не подходит

Для простого вычисления по каждой ячейке достаточно двух циклов. Для weighted paths обычный BFS не даёт минимум веса.

## 5. Необходимый Python

Размеры `rows/cols`, направления, set или изменение grid, deque.

## 6. Универсальный шаблон

```python
directions = ((1, 0), (-1, 0), (0, 1), (0, -1))
for dr, dc in directions:
    nr, nc = row + dr, col + dc
    if 0 <= nr < rows and 0 <= nc < cols:
        ...
```

## 7. Первая задача: LC 733 Flood Fill

Если исходный цвет уже новый — вернуть сразу. Иначе BFS/DFS, отмечая клетку при добавлении, не при извлечении.

## 8. Вторая задача: LC 200 Number of Islands

Каждая новая земля запускает DFS и увеличивает число компонент. Visited можно хранить отдельно или менять grid, если разрешено.

## 9. Третья задача без решения

LC 994: [[10_Trees_и_Grid_задачи#LC 994 — Rotting Oranges]]. Почему источники нужно добавить в queue одновременно?

## 10. Трассировка multi-source BFS

Минута 0: все rotten. Минута 1: их свежие соседи. Минута 2: следующий слой.

## 11. Инвариант

Отмеченная клетка уже поставлена в обход и не будет добавлена снова; в BFS слой соответствует одинаковому расстоянию.

## 12. Сложность

O(rows·cols) время и до O(rows·cols) памяти.

## 13. Типичные ошибки

Пустая matrix; использовать `len(grid[0])` до проверки; перепутать rows/cols; отметить слишком поздно; изменить вход без разрешения; диагонали без условия; забыть unreachable cells.

## 14. Что сказать интервьюеру

> Рассматриваю grid как неявный граф. Для каждой клетки генерирую до четырёх соседей с проверкой границ. Отмечаю при добавлении, поэтому каждая клетка обрабатывается максимум один раз: O(rows·cols).

## 15. Мини-контрольная

Почему mark on enqueue? Когда multi-source BFS? Цена? Нужен ли отдельный graph? Что если grid пуст?

<details><summary>Ответы</summary>
Нет дублей; несколько одновременных источников/минимальное время; O(RC); нет; early return.
</details>

## 16. Практика

Обязательные: 733, 200. Дополнительная: 994. Повтор: написать bounds без подсказки.

## 17. Шпаргалка

Grid = graph; directions; bounds; mark on enqueue/entry; BFS for shortest layers.

## Где это встречается в Data Science

Компоненты на изображениях/масках и пространственная связность; в реальной работе применяются оптимизированные библиотеки.
