# 09. Monotonic Stack

[[08_Stack_Queue_Deque|← Предыдущий]] · [[10_Intervals|Следующий →]]

## 1. Цель урока

Распознавать «следующий больший/меньший» и хранить только ещё не разрешённые индексы.

## 2. Главная идея

Stack поддерживается монотонным. Новый элемент разрешает ответы для вершины, пока нарушает порядок.

## 3. Как распознать

Следующий/предыдущий больший или меньший элемент, ближайший день/цена, расстояние до события.

## 4. Когда не подходит

Нужен глобальный максимум → один проход. Нужен Top-K → heap. Нужны произвольные range queries → другая структура.

## 5. Необходимый Python

Stack индексов, `while stack and ...`, `enumerate`.

## 6. Универсальный шаблон

```python
stack: list[int] = []
for index, value in enumerate(values):
    while stack and values[stack[-1]] < value:
        previous = stack.pop()
        answer[previous] = index - previous
    stack.append(index)
```

## 7. Первая задача: локальный next greater

Код выше. Индексы нужны, чтобы вернуть расстояние.

## 8. Вторая задача: LC 739 Daily Temperatures

Тот же шаблон; ответы неразрешённых индексов остаются 0.

## 9. Третья задача без решения

Измените условие для «следующего меньшего». Что делать с равными значениями? Ответ зависит от строгого/нестрогого требования.

## 10. Трассировка `[73,74,71,75]`

| i/value | pop | stack после |
|---|---|---|
| 0/73 | — | [0] |
| 1/74 | 0 | [1] |
| 2/71 | — | [1,2] |
| 3/75 | 2,1 | [3] |

## 11. Инвариант

Индексы в stack ещё не имеют ответа; их значения монотонны.

## 12. Сложность

O(n): каждый индекс push/pop не более одного раза. Память O(n).

## 13. Типичные ошибки

Хранить значения вместо индексов; использовать `if`; неверный знак сравнения; потерять равные; считать while квадратичным; забыть значения без ответа.

## 14. Что сказать интервьюеру

> Stack хранит индексы без найденного следующего большего значения и остаётся монотонным. Новый элемент снимает все меньшие вершины и даёт им ответ. Каждый индекс входит и выходит один раз, поэтому O(n).

## 15. Мини-контрольная

Почему индексы? Почему O(n)? Что остаётся в stack? `>` или `>=`? Что для unresolved?

<details><summary>Ответы</summary>
Расстояние/доступ к значению; один push/pop; без ответа; зависит от условия; default 0/-1.
</details>

## 16. Практика

Обязательная: 739. Дополнительно: самостоятельно next greater. Повтор через 3 дня.

## 17. Шпаргалка

`while stack and new resolves top: pop`; затем push текущий индекс.

## Где это встречается в Data Science

Редко напрямую, но полезен для линейного анализа последовательностей и понимания амортизированной сложности.
