# Чек-лист DL-проекта

## Задача и данные

- [ ] Определены объект, target и момент прогноза.
- [ ] Выбрана главная метрика.
- [ ] Есть простой baseline.
- [ ] Final test отделён до экспериментов.
- [ ] Учтены группы и время.
- [ ] Проверены exact/near duplicates.
- [ ] Preprocessing fit только на train.

## Формы и модель

- [ ] Известны формы входа, target и logits.
- [ ] Target имеет правильный dtype.
- [ ] Последний слой соответствует задаче.
- [ ] Loss соответствует форме target.
- [ ] Нет лишнего sigmoid/softmax.
- [ ] Посчитано число обучаемых параметров.

## Обучение

- [ ] Проверен один forward.
- [ ] Loss конечный.
- [ ] Есть gradients.
- [ ] Модель переобучает один batch.
- [ ] Train использует `model.train()`.
- [ ] Valid использует `model.eval()` и `inference_mode`.
- [ ] Сохраняются лучшие, а не последние веса.
- [ ] Логируются loss, метрика, lr и ресурсы.

## Оценка

- [ ] Решения принимаются только по valid.
- [ ] Threshold выбирается только по valid.
- [ ] Метрика соответствует production-задаче.
- [ ] Проведён анализ ошибок.
- [ ] Проверены классы/сегменты/длина/время.
- [ ] Final test оценён один раз.

## Воспроизводимость и inference

- [ ] Сохранены weights и config.
- [ ] Сохранены tokenizer/scaler/class mapping.
- [ ] Зафиксированы seed, data version и code version.
- [ ] Проверен inference на новом объекте.
- [ ] Измерены latency и память.
- [ ] Обработаны пустые/длинные/невалидные входы.

## Готовность к защите

- [ ] Могу объяснить baseline.
- [ ] Могу нарисовать формы одного batch.
- [ ] Могу объяснить loss и метрику.
- [ ] Могу назвать главные утечки.
- [ ] Могу объяснить одну неудачную гипотезу.
- [ ] Могу показать, как проверял модель.
- [ ] Могу честно назвать ограничения.
