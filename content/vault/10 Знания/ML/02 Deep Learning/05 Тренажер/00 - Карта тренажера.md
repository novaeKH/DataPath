# Карта DL-тренажёра

## Deep Learning — тренажёр собеседования

**Цель:** превратить знания из основного ноутбука в навык ответа, расчёта и чтения кода.

Сначала пройди `DL_Interview_Course_Sber_RU.ipynb`, затем используй этот файл как экзамен и повторение.

Правила:

1. Ответь вслух за 30–60 секунд.
2. Запиши формулу/форму тензора без подсказки.
3. Только затем открой ответ.
4. Поставь себе балл: `1` — верно и уверенно, `0.5` — идея верна, но нужны подсказки, `0` — не ответил.

**Готовность:** не менее 80% в каждом обязательном блоке, а не только по общей сумме.
