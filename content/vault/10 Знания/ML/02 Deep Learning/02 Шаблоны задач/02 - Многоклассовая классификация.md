# Шаблон — многоклассовая классификация

Ровно один правильный класс из `C`.

## Формула

```text
logits [B,C]
target [B] long с id 0..C-1
→ CrossEntropyLoss
→ argmax(dim=1)
```

## Модель

```python
from torch import nn


class MulticlassMLP(nn.Module):
    def __init__(self, input_dim: int, num_classes: int):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(input_dim, 128),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(128, num_classes),
        )

    def forward(self, features):
        return self.network(features)


model = MulticlassMLP(num_features, num_classes).to(device)
criterion = nn.CrossEntropyLoss()
```

## `task_step`

```python
def multiclass_step(model, batch, device):
    features, targets = batch
    features = features.to(device)
    targets = targets.long().to(device)

    logits = model(features)          # [B,C]
    loss = criterion(logits, targets) # target [B]

    return loss, features.size(0)
```

## Прогноз и метрики

```python
predictions = logits.argmax(dim=1)
probabilities = torch.softmax(logits, dim=1)  # если нужны
```

```python
from sklearn.metrics import classification_report, f1_score


macro_f1 = f1_score(
    y_true,
    y_pred,
    average="macro",
)

print(classification_report(y_true, y_pred, zero_division=0))
```

Для банковских обращений при дисбалансе главная стартовая метрика — `macro F1`, затем per-class Recall.

## Веса классов

```python
class_weights = torch.tensor(
    weights,
    dtype=torch.float32,
    device=device,
)

criterion = nn.CrossEntropyLoss(weight=class_weights)
```

Проверяй, улучшились ли редкие классы, а не только общий loss.

## Типовые ошибки

- target one-hot `[B,C]`, хотя ожидается `[B]`;
- target `float`, а нужен `long`;
- `softmax` перед `CrossEntropyLoss`;
- output layer имеет не `C` выходов;
- macro F1 не считается, хотя классы несбалансированы.
