# Шаблон — DL-регрессия

## Формула

```text
output [B] или [B,K]
target той же формы, float
→ MSE / L1 / Huber
→ MAE/RMSE на validation
```

## Модель

```python
class RegressionMLP(torch.nn.Module):
    def __init__(self, input_dim: int, output_dim: int = 1):
        super().__init__()
        self.network = torch.nn.Sequential(
            torch.nn.Linear(input_dim, 128),
            torch.nn.ReLU(),
            torch.nn.Dropout(0.1),
            torch.nn.Linear(128, output_dim),
        )

    def forward(self, features):
        return self.network(features)


model = RegressionMLP(num_features).to(device)
criterion = torch.nn.HuberLoss()
```

## `task_step`

```python
def regression_step(model, batch, device):
    features, targets = batch
    features = features.to(device)
    targets = targets.float().to(device)

    predictions = model(features).squeeze(-1)
    loss = criterion(predictions, targets)

    return loss, features.size(0)
```

## Как выбрать loss

| Loss | Когда |
|---|---|
| `MSELoss` | крупные ошибки нужно сильно штрафовать |
| `L1Loss` | нужна устойчивость к выбросам |
| `HuberLoss` | компромисс MSE и MAE |

## Метрики

```python
from sklearn.metrics import (
    mean_absolute_error,
    mean_squared_error,
    r2_score,
)


mae = mean_absolute_error(y_true, y_pred)
rmse = mean_squared_error(y_true, y_pred) ** 0.5
r2 = r2_score(y_true, y_pred)
```

## Если target сильно скошен

Для неотрицательной величины можно обучаться на:

```python
y_train_log = np.log1p(y_train)
```

Вернуть исходный масштаб:

```python
y_pred = np.expm1(y_pred_log)
```

Метрики и анализ ошибок считай также в исходных единицах.

## Обязательные сравнения

- константа: среднее/медиана;
- линейная модель;
- CatBoost/другой бустинг для таблиц;
- DL-модель.

## Типовые ошибки

- выходная `sigmoid`, хотя target не ограничен `[0,1]`;
- разные формы `[B,1]` и `[B]`, приводящие к broadcasting;
- стандартизация до split;
- метрика посчитана в log-space и выдана как ошибка в исходных единицах;
- DL используется для таблиц без сравнения с бустингом.
