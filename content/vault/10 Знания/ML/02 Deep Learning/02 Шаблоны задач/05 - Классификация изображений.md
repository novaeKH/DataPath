# Шаблон — классификация изображений

Для небольшой выборки начинай с transfer learning, а не с CNN с нуля.

## Формы

```text
image  [B,3,H,W]
logits [B,C]
target [B] long
loss   CrossEntropyLoss
```

## Train и validation transforms

```python
from torchvision import transforms


train_transform = transforms.Compose([
    transforms.RandomResizedCrop(224),
    transforms.RandomHorizontalFlip(),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225],
    ),
])

valid_transform = transforms.Compose([
    transforms.Resize(256),
    transforms.CenterCrop(224),
    transforms.ToTensor(),
    transforms.Normalize(
        mean=[0.485, 0.456, 0.406],
        std=[0.229, 0.224, 0.225],
    ),
])
```

Случайные аугментации — только train.

## Pretrained backbone

```python
from torch import nn
from torchvision.models import ResNet18_Weights, resnet18


weights = ResNet18_Weights.DEFAULT
model = resnet18(weights=weights)

for parameter in model.parameters():
    parameter.requires_grad = False

model.fc = nn.Linear(model.fc.in_features, num_classes)
model = model.to(device)
```

Сначала обучи только head. Затем при необходимости разморозь последние блоки и уменьши learning rate.

## `task_step`

```python
criterion = nn.CrossEntropyLoss()


def image_step(model, batch, device):
    images, targets = batch
    images = images.to(device)
    targets = targets.long().to(device)

    logits = model(images)
    loss = criterion(logits, targets)

    return loss, images.size(0)
```

## Разморозка

```python
for parameter in model.layer4.parameters():
    parameter.requires_grad = True

optimizer = torch.optim.AdamW([
    {"params": model.layer4.parameters(), "lr": 1e-5},
    {"params": model.fc.parameters(), "lr": 1e-4},
])
```

## Метрики и анализ

- macro F1 и per-class Recall при дисбалансе;
- confusion matrix;
- ошибки по источнику, освещению и качеству;
- просмотр уверенных ошибок;
- проверка сдвига train → production.

## Утечки

Не разносить по split:

- кадры одного видео;
- снимки одного пациента/объекта;
- версии одного изображения;
- изображения с одинаковым фоном/серией, если серия раскрывает target.

## Типовые ошибки

- train augmentation используется на valid;
- неправильная normalization для pretrained weights;
- весь backbone разморожен сразу на маленьком датасете;
- `model.eval()` не вызывается;
- split по изображениям вместо объекта/серии.

Официальная сверка API: [PyTorch Transfer Learning Tutorial](https://docs.pytorch.org/tutorials/beginner/transfer_learning_tutorial.html).
