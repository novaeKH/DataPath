## Быстрая развилка для классификации

```text
Один объект имеет:

ровно один из C классов?
→ CrossEntropyLoss, target [B] long

несколько независимых меток?
→ BCEWithLogitsLoss, target [B,C] float

только один бинарный ответ?
→ BCEWithLogitsLoss, target [B] float
```

## Быстрая развилка для NLP

```text
Один label на весь текст
→ sequence classification

Один label на каждый токен
→ token classification / NER

Нужно получить вектор текста
→ embedding model

Нужно оценить пару query-document
→ cross-encoder reranker

Нужно генерировать следующий токен
→ causal LM
```
