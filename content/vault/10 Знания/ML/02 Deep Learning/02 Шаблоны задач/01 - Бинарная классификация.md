# Шаблон — бинарная классификация

## Формула

```text
logits [B]
target [B] float
→ BCEWithLogitsLoss
→ sigmoid
→ threshold
```

## Минимальная модель

```python
import torch
from torch import nn


class BinaryMLP(nn.Module):
    def __init__(self, input_dim: int):
        super().__init__()
        self.network = nn.Sequential(
            nn.Linear(input_dim, 64),
            nn.ReLU(),
            nn.Dropout(0.2),
            nn.Linear(64, 1),
        )

    def forward(self, features):
        return self.network(features).squeeze(-1)


model = BinaryMLP(input_dim=num_features).to(device)
criterion = nn.BCEWithLogitsLoss()
```

## `task_step`

```python
def binary_step(model, batch, device):
    features, targets = batch
    features = features.to(device)
    targets = targets.float().to(device)

    logits = model(features)              # [B]
    loss = criterion(logits, targets)     # [B] vs [B]

    return loss, features.size(0)
```

## Прогноз

```python
probabilities = torch.sigmoid(logits)
predictions = (probabilities >= threshold).long()
```

`threshold=0.5` — только старт. Выбирать его нужно на validation.

## Дисбаланс

```python
pos_weight = torch.tensor(
    [num_negative / num_positive],
    dtype=torch.float32,
    device=device,
)

criterion = nn.BCEWithLogitsLoss(pos_weight=pos_weight)
```

`pos_weight` меняет обучение, но не отменяет подбор threshold и проверку Precision/Recall.

## Метрики

```python
from sklearn.metrics import (
    average_precision_score,
    f1_score,
    precision_score,
    recall_score,
    roc_auc_score,
)


metrics = {
    "ap": average_precision_score(y_true, probabilities),
    "roc_auc": roc_auc_score(y_true, probabilities),
    "f1": f1_score(y_true, predictions),
    "precision": precision_score(y_true, predictions, zero_division=0),
    "recall": recall_score(y_true, predictions, zero_division=0),
}
```

При сильном дисбалансе начни с AP/PR-AUC, Precision и Recall, а не Accuracy.

## Что менять в новой задаче

```text
input_dim
архитектуру hidden layers
pos_weight при необходимости
главную метрику
правило выбора threshold
```

## Типовые ошибки

- `sigmoid` внутри модели и затем `BCEWithLogitsLoss`;
- target типа `long`;
- logits `[B,1]`, target `[B]` без осознанного выравнивания;
- threshold подобран на test;
- Accuracy используется при редком положительном классе.

## Готовность

- [ ] Один forward даёт `[B]`.
- [ ] Target имеет `float32` и `[B]`.
- [ ] Loss конечный.
- [ ] Модель переобучается на одном батче.
- [ ] Threshold выбран только на valid.
