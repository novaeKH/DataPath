# Matplotlib and Seaborn EDA — Practice

## Задача

Для tabular classification dataset подготовьте одну figure из четырёх осмысленных plots:

1. target prevalence и support;
2. numerical distribution по target;
3. missing rate по времени;
4. segment metric с sample size.

## Критерии

- каждый plot отвечает на сформулированный вопрос;
- оси и units подписаны;
- сравнимые panels имеют совместимые scales;
- palette различима в light/dark export;
- показаны counts/uncertainty там, где это важно;
- нет вывода о причинности.
