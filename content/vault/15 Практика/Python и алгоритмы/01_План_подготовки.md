## Ритм каждого дня

1. Один блок теории: выпишите 5 тезисов.
2. Один блок разбора шаблона: сигнал, состояние, инвариант.
3. Два–три блока задач без решения перед глазами.
4. Один короткий устный опрос и code review.
5. Обновление [[LeetCode_Tracker]] и повтор старых задач.

## Интервальное повторение

После первого решения назначьте:

- +1 день: восстановить идею и написать код;
- +3 дня: решить без заметок;
- +7 дней: решить с таймером и объяснить вслух;
- перед собеседованием: только задачи со статусом «Нужно повторить» и ядро курса.
