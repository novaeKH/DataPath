# Python Interview Preparation: DS / ML intern и junior

Практический маршрут по Python, структурам данных и переносимым алгоритмическим шаблонам. Это не энциклопедия: сначала обязательный минимум, затем самостоятельная практика, устное объяснение и повторение.

## Быстрый старт

1. Выберите маршрут в [[01_План_подготовки]].
2. Перед первой задачей прочитайте [[02_Как_решать_задачи_на_собеседовании]].
3. Теорию изучайте вместе с задачами по [[Карта_тем|карте тем]].
4. Открывайте условие только в `Practice/Задачи_без_решений`; подсказки и решения лежат отдельно.
5. После каждой задачи обновляйте [[LeetCode_Tracker]] и назначайте повторы +1, +3 и +7 дней.

## Правило курса

Если решение не приходит за 20–25 минут:

1. запишите brute force и его сложность;
2. откройте только подсказку уровня 1;
3. через 5–10 минут — уровень 2;
4. уровень 3 используйте перед решением;
5. полное решение смотрите последним;
6. закройте его и воспроизведите код и объяснение с нуля.

## Что считать готовностью

Тема усвоена, если вы можете без конспекта:

- узнать шаблон по сигналам условия;
- назвать состояние и инвариант;
- написать читаемый Python 3.11+ код;
- оценить время и дополнительную память;
- объяснить решение за 30–60 секунд;
- повторно решить ключевую задачу через семь дней.
