## Как расширять каталог

1. Создать course manifest по [[Шаблон — курс]].
2. Разбить путь на модули.
3. Для каждого урока сослаться на canonical `content_path`.
4. Добавить mini-case после связной группы тем.
5. Обновить каталог командой `python tools/build_catalog.py`.
