# Мини-кейс — Сегментация клиентов

> [!case] Контекст
> Подготовить признаки поведения клиентов, масштабировать их, исследовать несколько k и использовать PCA только для анализа структуры и визуализации. Нельзя выдавать кластеры за истинные типы клиентов.

## Что нужно сдать

- feature table
- обоснование scaling
- сравнение k
- интерпретация с оговорками

## Режимы

- **Guided:** этапы и ограниченные подсказки.
- **Standard:** контрольные точки без готового плана.
- **Interview:** устная защита и follow-up.
- **Real-world:** часть проблем нужно обнаружить самостоятельно.
