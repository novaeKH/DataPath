- синтаксис всех Python-блоков Markdown;
- разрешение Obsidian-ссылок;
- число условий, подсказок и решений;
- импорт и выполнение всех файлов решений;
- по одному или нескольким функциональным тестам для каждой из 62 задач.

```text

```

## Ограничения

- Длительности и доступность YouTube верны на дату проверки; доступность может измениться позднее.
- LC 252 может требовать LeetCode Premium; локальная формулировка полностью покрывает шаблон Meeting Rooms.

- Генераторы в страницах «Задачи без решений» содержат `NotImplementedError` намеренно; исполняемые реализации находятся только в `Решения`.
