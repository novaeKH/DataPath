# Банк вопросов по Python

[[00_Главная_страница|← Главная]] · [[Алгоритмические_вопросы|Алгоритмы →]]

## Обязательный минимум

### 1. Чем `is` отличается от `==`?

**Ответ за 20 секунд:** `==` сравнивает значения через `__eq__`, `is` — идентичность объектов. `is` обычно нужен для `None`; на интернирование строк и чисел полагаться нельзя.

**Полный ответ:** Два разных списка могут быть равны по содержимому, но `a is b` будет False. `None` — singleton, поэтому пишут `value is None`. Пользовательский класс может определить собственное равенство, а идентичность переопределить нельзя.

**Дополнительные вопросы:** почему `1 is 1` иногда True? Что возвращать из `__eq__` для неизвестного типа?

### 2. Mutable и immutable

**20 секунд:** Mutable-объект меняется на месте (`list`, `dict`, `set`), immutable-операция создаёт новый объект (`int`, `str`, `tuple`). Несколько имён одного списка видят mutation.

**Полный ответ:** Присваивание не копирует объект. `append` меняет общий список; `x = x + [...]` связывает x с новым. Tuple неизменяем как контейнер ссылок, но вложенный list может меняться.

**Дополнительные:** почему `[[0]*m]*n` опасно? Что делает `+=` для list и tuple?

### 3. Shallow и deep copy

**20 секунд:** Shallow copy создаёт новый внешний контейнер, но делит вложенные объекты; deep copy рекурсивно создаёт независимый граф.

**Полный ответ:** `list(x)`, slice и `copy.copy` — поверхностные. `deepcopy` учитывает циклы, но может быть дорогим и плохо подходить ресурсам. Нужно копировать только требуемую глубину.

**Дополнительные:** копирует ли slice вложенные списки? Когда deepcopy нежелателен?

### 4. Как устроен list?

**20 секунд:** Это динамический массив ссылок. Индекс O(1), append амортизированно O(1), вставка/удаление в начале O(n) из-за сдвига.

**Полный ответ:** List резервирует лишнюю ёмкость. Редкий resize копирует ссылки, поэтому отдельный append может быть O(n), а серия — амортизированно O(1). Для операций слева подходит deque.

**Дополнительные:** `append` vs `extend`; `remove` vs `pop`; цена slice?

### 5. Как работает dict и почему не гарантировано O(1)?

**20 секунд:** Dict — хеш-таблица: hash даёт начальную позицию, коллизии разрешаются проверками других позиций. O(1) в среднем, O(n) теоретически.

**Полный ответ:** Ключ должен иметь стабильный hash; равные ключи обязаны иметь одинаковый hash. Resize поддерживает таблицу разреженной. Худший случай возможен при множестве коллизий или дорогих `__eq__`.

**Дополнительные:** почему list не ключ? Когда tuple не ключ? set vs dict?

### 6. Mutable default argument

**20 секунд:** Default вычисляется один раз при определении функции, поэтому список делится вызовами. Использовать `None` и создавать объект внутри.

**Полный ответ:** Объект хранится в `function.__defaults__`. Это иногда используется для кэша, но неявное общее состояние почти всегда ошибка.

**Дополнительные:** относится ли к dict/set? Когда default вычисляется?

### 7. Iterable, iterator, generator

**20 секунд:** Iterable даёт iterator через `iter`. Iterator выдаёт `next` до `StopIteration`. Generator — ленивый iterator через `yield`, обычно одноразовый.

**Полный ответ:** List — iterable, не iterator: каждый `iter(list)` создаёт новое состояние прохода. Generator сохраняет frame и локальные переменные между yield; после исчерпания повторный проход пуст.

**Дополнительные:** что делает `for`? Почему экономится память? Когда generator неудобен?

### 8. `yield` против `return`

**20 секунд:** `return` завершает обычную функцию; `yield` выдаёт значение и приостанавливает generator с сохранённым состоянием.

**Полный ответ:** Вызов generator function не исполняет тело. `next` продолжает до yield. `return` внутри генератора завершает его через `StopIteration`.

**Дополнительные:** `yield from`; как закрыть generator с ресурсом?

### 9. LEGB и closure

**20 секунд:** Имя ищется Local → Enclosing → Global → Builtins. Closure — функция, сохранившая доступ к enclosing-окружению.

**Полный ответ:** Присваивание делает имя локальным, если нет `global/nonlocal`. Late binding в цикле означает, что closure читает переменную при вызове; фиксируют default `i=i`.

**Дополнительные:** `global` vs `nonlocal`; почему все lambda вернули 2?

### 10. `__repr__` и `__str__`

**20 секунд:** `repr` — диагностическое представление для разработчика, `str` — человекочитаемое. При отсутствии `str` используется `repr`.

**Полный ответ:** `repr` желательно делать однозначным и полезным для debugging. `print` использует `str`, а интерактивная оболочка — `repr`.

**Дополнительные:** какой dunder обслуживает `len`, `in`, `obj[key]`, `obj()`?

### 11. Exception и context manager

**20 секунд:** Context manager гарантирует вход/выход вокруг блока; `with` вызывает `__enter__` и `__exit__`, что удобно для закрытия ресурсов.

**Полный ответ:** Ловят узкие ожидаемые исключения. `else` выполняется без ошибки, `finally` — для cleanup. `True` из `__exit__` подавляет исключение.

**Дополнительные:** почему голый except плох? `raise from`? `contextmanager`?

### 12. GIL, threads, processes, asyncio

**20 секунд:** В обычном CPython GIL не даёт двум threads одновременно исполнять Python bytecode. Threads подходят IO, processes — CPU-bound, asyncio — многому cooperative IO.

**Полный ответ:** IO и многие native-библиотеки освобождают GIL. Процессы имеют отдельную память и цену сериализации. NumPy переносит циклы в native code/BLAS и может использовать параллелизм.

**Дополнительные:** почему GIL не означает «нет параллелизма»? Что выбрать для API-запросов/чистого Python-цикла?

### 13. Почему NumPy быстрее Python-цикла?

**20 секунд:** Компактный типизированный массив и native loops уменьшают dispatch Python-объектов, используют SIMD/BLAS и иногда освобождают GIL.

**Полный ответ:** Векторизация переносит цикл из интерпретатора в оптимизированный код. Но может создавать временные массивы; важны dtype, contiguous layout, broadcasting и размер данных.

**Дополнительные:** всегда ли векторизация быстрее? Что такое временный массив?

## Уверенный junior

### 14. `classmethod`, `staticmethod`, `property`

**20 секунд:** classmethod получает `cls` и подходит альтернативным конструкторам; staticmethod не получает класс/объект; property даёт вычисляемый атрибут.

**Полный ответ:** Classmethod поддерживает наследование через `cls`. Staticmethod — namespace, но функция модуля может быть проще. Property позволяет менять реализацию, сохраняя API атрибута.

**Follow-up:** почему factory через `cls`, а не имя класса?

### 15. Связь `__eq__` и `__hash__`

**20 секунд:** Равные объекты обязаны иметь одинаковый hash; изменяемые объекты, равенство которых зависит от состояния, не должны быть ключами.

**Полный ответ:** Одинаковый hash не означает равенство. Dataclass `frozen=True` удобен для value object, если поля hashable.

**Follow-up:** что произойдёт, если изменить ключ после вставки?

### 16. `sort()` и `sorted()`

**20 секунд:** `list.sort` меняет list и возвращает None; `sorted` принимает iterable и возвращает новый list. Оба стабильны.

**Полный ответ:** Стабильность позволяет многошаговую сортировку. `key` вычисляется для каждого элемента и обычно яснее comparator.

**Follow-up:** как сортировать score по убыванию, имя по возрастанию?

### 17. `map/filter` и comprehension

**20 секунд:** В Python 3 map/filter ленивы; comprehension часто яснее для простой трансформации и фильтра.

**Полный ответ:** Generator expression сохраняет ленивость. `map` удобен с готовой именованной функцией или несколькими iterable.

### 18. Garbage collector

**20 секунд:** CPython использует reference counting, а cyclic GC собирает недостижимые циклы. `del` удаляет ссылку, не обязательно объект.

**Полный ответ:** Детерминированное освобождение — деталь CPython, ресурсы всё равно закрывают через `with`.

### 19. Decorator

**20 секунд:** Декоратор принимает callable и возвращает обёрнутый callable; `@d` эквивалентно `f=d(f)`. `wraps` сохраняет метаданные.

**Полный ответ:** Декоратор — применение функций как объектов и closures. С параметрами появляется дополнительный уровень factory.

### 20. Type hints

**20 секунд:** Аннотации документируют контракт и проверяются статическими инструментами; Python сам обычно не валидирует их runtime.

**Полный ответ:** Принимайте общий протокол (`Iterable`, `Sequence`) и возвращайте конкретный тип. `Any` выключает проверку.
