## Что делать сегодня

1. Ответить вслух на 10 вопросов уровня `A` из [[Вопросы к собеседованию|единого банка]].
2. Решить одну короткую задачу Python или SQL.
3. За 2 минуты рассказать об одном проекте по схеме «задача → данные → решение → результат → вывод».
4. Если выполнен [[03 Критерий достаточной подготовки|критерий достаточности]] — отправить отклик, даже если темы уровня `B` ещё не закрыты.

## Правило глубины

> [!important] Три слоя
> Сначала дай короткий ответ из Interview Note: **определение → механизм → trade-off → пример**. Для уровней C/D умей пройти под капот по [[Интервью — карта теории|Theory Notes]]: objective, leakage, параметры и follow-up. Глубину выбирай по уровню вопроса, а не по размеру заметки.
