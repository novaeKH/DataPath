# Практические задачи для DS интервью

[[00 Карьера — карта|← Карьера Data Science]]

## Python — 10 задач

- [ ] Частоты элементов и top-k.
- [ ] Удаление дублей с сохранением порядка.
- [ ] Группировка записей по ключу.
- [ ] Скользящее среднее.
- [ ] Пересечение интервалов.
- [ ] Два указателя: сумма пары.
- [ ] Проверка корректности скобок.
- [ ] Реализовать `zip` или генератор батчей.
- [ ] Найти ошибку в функции обработки данных.
- [ ] Оценить сложность по времени и памяти.

## SQL — 20 задач

- [ ] 4 задачи на `JOIN`.
- [ ] 4 задачи на `GROUP BY` и `HAVING`.
- [ ] 4 задачи на оконные функции.
- [ ] 3 задачи на CTE и подзапросы.
- [ ] 2 задачи на даты и интервалы.
- [ ] 2 задачи на воронку или retention.
- [ ] 1 задача на дубли и качество данных.

## ML — 6 кейсов

- [ ] Кредитный дефолт: target, split, метрика, порог.
- [ ] Отток клиента: момент прогноза и стоимость ошибок.
- [ ] Отклик на предложение: propensity против uplift.
- [ ] Прогноз спроса: временной split и сезонность.
- [ ] Рекомендации: offline-метрика и online-проверка.
- [ ] Модель ухудшилась после запуска: диагностика drift и pipeline.

## Формат решения кейса

1. Уточнить объект, target и момент прогноза.
2. Назвать baseline.
3. Описать данные и риски утечки.
4. Выбрать split и метрику.
5. Предложить 1–2 модели.
6. Обсудить порог, анализ ошибок и внедрение.
7. Сказать, как проверить бизнес-эффект.
