# Hermes instructions for DataPath vault

This repository is an Obsidian knowledge base and course-content source for the DataPath application.

Before editing, read:
- `_meta/VAULT_SPEC.md`
- `_meta/DATAPATH_CONTENT_SPEC.md`
- `_meta/DATAPATH_RAG_POLICY.md`
- `_meta/DATAPATH_AGENT_GUIDE.md`

Rules:
1. Preserve one canonical owner per concept. Course lessons reference canonical notes instead of copying them.
2. Use only official documentation, primary papers, or established university/open textbooks for new facts. Register sources in `_meta/SOURCE_REGISTRY.yml`.
3. Stable `id` values are application contracts; never change them casually.
4. Keep `rag` and `app` explicit. MOC, lesson wrappers, templates, metadata and source registries are excluded from RAG.
5. User progress, weak topics and review scheduling belong in the app database, never in committed Markdown.
6. Run `python tools/validate_vault.py` and `python tools/build_catalog.py` after content changes.
7. Do not use sudo, do not push, and do not delete or mass-rename files without explicit approval.
