# DataPath 1.0.0

Дата релиза: 2026-08-10.

DataPath 1.0.0 — первый стабильный local-first выпуск. Он закрывает ежедневный учебный цикл:
Today рекомендует действие, Focus проводит через урок и интерактивное объяснение, Studio даёт
практику, Review возвращает материал по интервалам, а Atlas показывает реальное состояние знаний.

## Главное

- Девять областей и 86 уроков в release Roadmap; 103 source-backed урока в canonical vault.
- 57 валидируемых интерактивных visual demos и три отдельные ML-лаборатории.
- 15 упражнений, включая шесть исполняемых SQLite-задач, и 9 mini-cases.
- Одинаковый local-first runtime для Web/PWA, macOS и iOS без обязательного FastAPI.
- Версионированное состояние schema v2, безопасный backup/import, notes и resume.
- GitHub CI и subpath-safe GitHub Pages workflow.

## Обновление с 0.9.0 RC

Существующее локальное состояние переносится автоматически. Перед обновлением рекомендуется
сделать export в «Настройки → Backup учебного состояния». Импорт сначала проверяет формат, версию
и checksum и только затем заменяет текущие данные.

## Ограничения

Вне SQL приложение не исполняет произвольный Python. macOS artifact unsigned. iOS target создан и
синхронизирован, но установка на устройство требует Xcode и личного signing. Algorithms остаётся
внешним направлением AlgoPath и не входит в релизный интерфейс DataPath 1.0.0.
