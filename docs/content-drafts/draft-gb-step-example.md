## Пример: 3 шага Gradient Boosting на synthetic data (дополнение)

**Задача:** регрессия. Предсказать цену квартиры по площади.
**Данные (5 объектов):**

| Площадь (м²) | Цена (млн ₽) |
|---|---|
| 30 | 3.0 |
| 45 | 4.5 |
| 60 | 6.0 |
| 75 | 7.0 |
| 90 | 9.5 |

**Шаг 0 — начальное приближение:**
$$
F_0 = \text{mean}(y) = \frac{3.0 + 4.5 + 6.0 + 7.0 + 9.5}{5} = 6.0
$$

**Шаг 1:**
- Считаем остатки: $r_i = y_i - F_0(x_i)$
- Остатки: [-3.0, -1.5, 0.0, +1.0, +3.5]
- Обучаем маленькое дерево $h_1$ на остатках.
- Дерево глубины 1 (stump): «площадь ≤ 52.5?» → левый лист: mean(-3.0, -1.5) = -2.25; правый: mean(0, 1.0, 3.5) = +1.5
- Обновление с learning rate $\eta = 0.3$:
  $F_1(x) = F_0(x) + 0.3 \cdot h_1(x)$

| Площадь | $F_0$ | $h_1$ | $0.3 \cdot h_1$ | $F_1$ | Остаток после шага 1 |
|---|---|---|---|---|---|
| 30 | 6.0 | -2.25 | -0.675 | 5.325 | -2.325 |
| 45 | 6.0 | -2.25 | -0.675 | 5.325 | -0.825 |
| 60 | 6.0 | +1.5 | +0.45 | 6.45 | -0.45 |
| 75 | 6.0 | +1.5 | +0.45 | 6.45 | +0.55 |
| 90 | 6.0 | +1.5 | +0.45 | 6.45 | +3.05 |

**Шаг 2:**
- Обучаем новое дерево $h_2$ на остатках после шага 1.
- И так далее — каждый шаг исправляет ошибки предыдущего ансамбля.

**Результат после 3 шагов (приблизительно):**

| Площадь | Истинная цена | $F_3$ (предсказание) | Ошибка |
|---|---|---|---|
| 30 | 3.0 | 3.2 | +0.2 |
| 45 | 4.5 | 4.7 | +0.2 |
| 60 | 6.0 | 5.9 | -0.1 |
| 75 | 7.0 | 7.1 | +0.1 |
| 90 | 9.5 | 9.1 | -0.4 |

Ошибка уменьшилась с [-3.0, +3.5] на шаге 0 до [-0.4, +0.2] на шаге 3.

**Ключевые наблюдения:**
- Каждый новый шаг корректирует ошибки предыдущего ансамбля.
- Обучение **последовательное** — нельзя распараллелить.
- Learning rate $\eta = 0.3$ замедляет обучение, но улучшает обобщение.

**Примечание для ручной проверки:**
- Проверить арифметику.
- Заменить synthetic данные на реальные (например, California Housing) при желании.
