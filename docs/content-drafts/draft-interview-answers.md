## Decision Tree — ответ для собеседования

Decision Tree — это алгоритм, который рекурсивно делит пространство признаков
вопросами вида «feature ≤ threshold?». На каждом шаге выбирается разбиение,
максимизирующее уменьшение impurity (Gini для классификации, MSE для регрессии).
Плюсы: интерпретируемость, не требует scaling, автоматически отбирает признаки.
Минусы: склонность к переобучению, нестабильность (малые изменения данных меняют
структуру). Решается регуляризацией (max_depth, min_samples_leaf) и ансамблями.

## Bias-Variance Trade-off — ответ для собеседования

Ошибка модели раскладывается на bias (систематическая ошибка из-за упрощения),
variance (чувствительность к конкретной выборке) и неустранимый шум. Простые модели
(линейная регрессия) имеют высокий bias, низкую variance. Сложные (глубокое дерево) —
наоборот. Оптимальная сложность минимизирует сумму. Regularization (L1/L2, early stopping)
снижает variance ценой небольшого роста bias. Практический признак high variance —
большой разрыв между train и validation метриками.

## Random Forest — ответ для собеседования

Random Forest — ансамбль decision trees, где каждое дерево обучается на bootstrap-выборке
строк и случайном подмножестве признаков на каждом split. Предсказание — усреднение
(регрессия) или голосование (классификация). Ключевая идея: усреднение некоррелированных
деревьев снижает variance без роста bias. Преимущества: стабильнее одного дерева,
OOB-оценка заменяет validation set, feature importance. Ограничения: не экстраполирует
за пределы данных, хуже boosting на сложных зависимостях.

## Gradient Boosting — ответ для собеседования

Gradient Boosting строит ансамбль последовательно: каждая новая модель (обычно мелкое
дерево) исправляет ошибки предыдущего ансамбля. Ошибки измеряются через anti-gradient
функции потерь (pseudo-residuals). Ключевые гиперпараметры: learning rate (чем меньше,
тем больше итераций нужно, но лучше обобщение), глубина деревьев (обычно 3–6),
число итераций (контролируется early stopping). Преимущества: state-of-the-art на
табличных данных, гибкость (любая дифференцируемая функция потерь). Ограничения:
последовательное обучение (нельзя распараллелить), склонность к переобучению при
малом learning rate и большом числе итераций.

---

## CatBoost / XGBoost / LightGBM — ответ для собеседования

Все три — оптимизированные реализации gradient boosting. XGBoost использует
вторые производные (Hessian) для более точного поиска splits и встроенную
L1/L2-регуляризацию. LightGBM ускоряет обучение через histogram-based поиск
splits и leaf-wise (вместо level-wise) рост деревьев. CatBoost решает проблему
категориальных признаков через ordered target statistic — encoding без утечки
целевой переменной. Выбор: CatBoost — при обилии категорий, LightGBM — при
больших данных и ограниченном времени, XGBoost — при необходимости тонкой
настройки и зрелой экосистеме.

## Как выбрать модель (ensemble selection) — ответ для собеседования

Начинаю с Random Forest как baseline: стабилен, не требует сложной предобработки,
даёт честную OOB-оценку. Если качество недостаточно, перехожу к Gradient Boosting
(XGBoost/LightGBM/CatBoost) с early stopping на validation set. CatBoost выбираю
при большом количестве категориальных признаков — ordered encoding защищает от
data leakage. Для задач, где важна интерпретируемость (банки, медицина), остаюсь
на Decision Tree или RF с SHAP-анализом. Всегда калибрую вероятности (Platt scaling)
перед сравнением моделей по вероятностным метрикам.
