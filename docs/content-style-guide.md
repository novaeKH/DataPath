# DataPath — стандарт учебного контента

Короткий редакционный стандарт для canonical-уроков и кейсов.

## Урок

- Один урок решает одну основную учебную задачу. Определение не становится отдельным микро-уроком.
- Сначала реальная проблема и небольшой пример, затем термин и формула.
- Новое понятие либо объяснено до использования, либо помечено как необязательное углубление со ссылкой.
- Используется progressive disclosure: **обязательно сейчас → рекомендуется → углубление**. Углубление не блокирует первый практический проход.
- Текст пишется на естественном русском. Английский термин вводится один раз, если нужен для документации, API или собеседования. Названия классов, методов и метрик не переводятся.
- Перед формулой сказано, какой вопрос она решает. После формулы объяснены символы, единицы, числовой пример и дальнейшее применение.
- Хорошая тема связывает интуицию, механизм, код, визуализацию, ошибки, самопроверку и практику. Структура адаптируется к теме, а не копируется механически.
- Практика идёт ступенями: показанный пример → совместное решение → подсказка от общего к конкретному → самостоятельная задача → отладка.
- Проверка понимания спрашивает «почему» и «что изменится», а не только определение.

## Связи Math ↔ ML

- Математическая тема должна отвечать на вопрос из модели, а ML-урок — вести к соответствующему углублению.
- `prerequisites` содержит только действительно обязательные уроки. Рекомендованные и углублённые материалы не запирают маршрут.
- Stable lesson/course IDs, `canonical_number` и `content_path` не меняются при редакционной переработке.

## Кейс

- Кейс начинается с заказчика, решения, объекта, целевой переменной и момента прогноза.
- До модели ученик формулирует ожидаемые проблемы и проводит аудит данных.
- Скрытые проблемы хранятся в структуре кейса и показываются только после попытки.
- Сначала строится простая базовая модель, затем основная модель урока.
- Итог включает метрики, анализ крупнейших ошибок и ограничения, а не заканчивается одним числом.
- Источник, лицензия и способ получения данных указаны явно; крупные датасеты не добавляются в git без необходимости.

## Будущие вертикальные маршруты

- Probability → MLE → Logistic Regression → Classification Case.
- Linear Algebra → Eigenvectors → PCA → Dimensionality Reduction Case.
- Calculus → Chain Rule → Neural Networks → DL Case.
- Categorical Distribution → likelihood → cross-entropy → Softmax.
- Loss derivatives → functional gradient → Gradient Boosting.

Это направления расширения, а не требование реализовать их внутри каждого текущего урока.
